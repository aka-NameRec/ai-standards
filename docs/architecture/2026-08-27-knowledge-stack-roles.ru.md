# Роли стека знаний

Английская версия: [2026-08-27-knowledge-stack-roles.md](2026-08-27-knowledge-stack-roles.md)

Описательный обзор стека знаний вокруг проекта. Аргументация этой формы — в [2026-08-24-knowledge-store-role-separation.ru.md](../decisions/2026-08-24-knowledge-store-role-separation.ru.md); часть про архив — в [2026-08-24-archive-history-in-docs-tree.ru.md](../decisions/2026-08-24-archive-history-in-docs-tree.ru.md).

## Слои

| Слой | Роль | Каноничен? |
|---|---|---|
| git | файлы проекта и полная история | да — всё остальное проекции |
| ai-standards | доставка правил: манифест → отрендеренный `AGENTS.md`; `sync-templates` раскладывает скиллы и инфраструктуру; `doctor` аудирует проводку | правила каноничны здесь |
| cockpit `projects_registry.toml` | мульти-проектный источник истины: расположения, opt-in Basic Memory, индексируемые пути | да, для проводки проектов |
| адаптер Basic Memory (cockpit) | детерминированная проекция реестра в `~/.basic-memory/config.json`; единственный писатель этого файла | нет — проекция |
| Basic Memory | графовый поиск по живому дереву знаний (`docs/**` без архива); заметки идентифицируются по `title` во frontmatter; `memory://` через пермалинки | нет — проекция дерева |
| Chroma | векторный поиск: кодовые коллекции по явным корням; коллекция истории над `docs/archive` | нет — проекция |
| ConPort | операционная память: активный контекст, прогресс, передача сессий | нет — транзиентная |

## Инварианты границ

- Файлы в git каноничны; каждый индекс пересобирается из них.
- Агент пишет `title` во frontmatter; индексатор штампует `permalink`. Заметке, не требующей ремонта, хватает `title`, совпадающего с `# H1`, и финальных секций `## Observations` и `## Relations`.
- Архив покидает граф Basic Memory одной конвенционной строкой `.bmignore` (`archive/`), проверяемой `ai-sync doctor`; входит в Chroma одним объявлением коллекции.
- Кодовые коллекции объявляют явные корни, не накрывающие `docs/archive`; корень `"."` примешал бы историю в кодовый индекс.
- Реестр — единственный писатель глобального конфига Basic Memory; `doctor` этот конфиг только читает.

## Контракт поиска

- Текущая работа опрашивает живой граф (Basic Memory) и кодовые коллекции; архивный материал не всплывает сам.
- Явное исследование истории обращается к коллекции истории по имени.
- Вики-ссылки резолвятся внутри живого дерева; ссылки в архив — относительные Markdown-ссылки, работающие в git и при чтении.

## Observations

- [fact] git — единственный канонический слой; Basic Memory, Chroma, ConPort и отрендеренный `AGENTS.md` — проекции, пересобираемые из файлов.
- [fact] Конвейер «реестр → конфиг» однописательный: адаптер cockpit пишет `~/.basic-memory/config.json`, а `ai-sync doctor` его только читает.
- [fact] Архив пересекает границу Basic Memory через `.bmignore`, а границу Chroma — через объявление коллекции: по одной строке, с разной верификацией.
