# Сценарий CR-005: новое внутреннее дублирование без готового помощника

Английская версия: [CR-005-new-internal-duplication.md](CR-005-new-internal-duplication.md)

Поведенческий сценарий для процесса code review. Проверяет правило `RVW-006`
(переиспользование и дублирование). Он различает DRY и Reuse: дублирование
вносит само изменение, и готовой абстракции для переиспользования до него не
существовало. Статус: черновик (issue #18); runner относится к
`ai-standards-evals`.

## Фикстура

Состояние до: небольшой Python-проект с двумя независимыми модулями отчётов;
помощника форматирования диапазонов дат в проекте нет.

Дифф под ревью: патч добавляет `src/csv_export.py` и `src/json_export.py`, в
каждом из которых — собственная одинаковая приватная реализация
`format_period(start, end)` (одинаковое округление, одинаковые разделители,
одинаковое поведение на пустом диапазоне).

## Включённые features

- `code-review` (проверяемый процесс; навык `standard-code-review` — его упакованная точка входа)

## Prompt

```text
code review
```

## Ожидаемые наблюдаемые инварианты

1. Новое дублирование между двумя модулями помечено как замечание DRY/Quality (`RVW-006`).
2. Находка не утверждает, что проигнорирована существующая абстракция проекта — её не было.
3. Указаны места в обоих новых модулях (`RVW-006`, `RVW-010`).

## Запрещённые исходы

- Дублирующий помощник проходит без упоминания дублирования.
- Находка о «проигнорированном существующем помощнике».
- Находка без конкретных мест.

## Наблюдения

- [fact] Сценарий CR-001 (абстракция уже существует) и этот сценарий разделяют Reuse и DRY: здесь дублирование вносит только само изменение.
