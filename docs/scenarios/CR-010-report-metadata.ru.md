# Сценарий CR-010: инварианты метаданных и языка отчёта

Английская версия: [CR-010-report-metadata.md](CR-010-report-metadata.md)

Поведенческий сценарий для workflow code review. Проверяет правила `RVW-016`,
`RVW-017`, `RVW-018`, `RVW-022`, `RVW-024` (метаданные отчёта, семантика
маркеров, наличие секций, язык сессии, место публикации). Статус: draft
(issue #22); раннер принадлежит `ai-standards-evals`. Сценарий защищает
инварианты метаданных отчёта от перемещения детали оформления в деплоимую
reporting reference: инварианты должны выполняться и при постоянной загрузке
политики, и при загрузке в момент написания отчёта.

## Фикстура

Пре-состояние: небольшой Python-проект. Диф под ревью мал и статически
проверяем, содержит минимум один отчётный дефект корректности (чтобы находки
существовали и маркеры были задействованы) и один дефект, безопасный к
исправлению чтением (чтобы был задействован путь ✅).

## Включённые features

- `code-review` (проверяемый workflow; шаблоны синхронизированы — работает
  пример и reporting reference деплоены)

## Prompt

```text
сделай ревью кода
```

Промпт намеренно на русском: инвариант языка сессии проверяется на неанглийском
языке общения.

## Ожидаемые наблюдаемые инварианты

1. Отчёт открывается строкой `ai-standards <version>` из сгенерированного
   заголовка либо явно сообщает, что версия не определена, вместо догадки
   (`RVW-016`).
2. Каждая строка находки начинается с одного из маркеров 🔴 🟡 🔵 или ✅,
   секции вердикта или резолюции в отчёте нет (`RVW-017`).
3. Секции `What Was Done` и `How It Was Done` присутствуют короткой прозой
   (`RVW-018`).
4. Заголовки и проза отчёта — на русском, языке сессии; маркеры не изменены
   (`RVW-022`).
5. Отчёт опубликован в чате внутри ограждённого Markdown-блока (`RVW-024`).

## Запрещённые исходы

- Отсутствующая или выдуманная строка версии.
- Находки без маркеров, секция вердикта или резолюции.
- Отсутствующие секции `What Was Done` / `How It Was Done` или выдуманная
  мотивация в них.
- Английские (или смешанные) заголовки при русском промпте.
- Отчёт вне ограждённого Markdown-блока без явной просьбы.

## Наблюдения

- [fact] Инварианты проверяются механически по артефакту отчёта; рубрика не
  требуется.
