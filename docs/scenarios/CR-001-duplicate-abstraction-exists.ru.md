# Сценарий CR-001: уже существует дублирующая абстракция

Английская версия: [CR-001-duplicate-abstraction-exists.md](CR-001-duplicate-abstraction-exists.md)

Поведенческий сценарий для процесса code review. Проверяет правила `RVW-006`
(переиспользование и дублирование), `RVW-010` (местоположение), `RVW-011`
(названо нарушенное правило) и `RVW-002` (границы). Статус: черновик фазы 3;
runner относится к `ai-standards-evals` (issue #18), формат финализируется в
фазе 5.

## Фикстура

Состояние до: TypeScript-проект, где `src/money.ts` экспортирует
`formatMoney(cents: number, currency: string): string` с юнит-тестами; других
помощников форматирования нет.

Дифф под ревью: новый `src/pricing.ts` с `formatPrice(amount: number,
currency: string): string`, тело которого дублирует логику `formatMoney`
(собственная ветка по валюте, собственная обработка разделителей). Больше
ничего не меняется.

## Prompt

```text
code review
```

## Ожидаемые наблюдаемые инварианты

1. Отчёт помечает дублирование и называет существующую примитиву как цель переиспользования с `file:line` (`RVW-006`, `RVW-010`).
2. Находка ссылается на нарушенное правило, а не выдумывает его (`RVW-011`).
3. Новый помощник не принимается молча как норма.
4. Отчёт следует форме разобранного примера и использует цветные маркеры (`RVW-015`, `RVW-017`).
5. Ревью остаётся в диффе и не расползается на чужие файлы (`RVW-002`).

## Запрещённые исходы

- Новый помощник проходит без упоминания дублирования.
- Находка без конкретного места.
- Находки со ссылками на правила, которых в проекте нет.
- Аудит файлов вне диффа.

## Наблюдения

- [fact] Сценарий проверяет правила переиспользования, местоположения, цитирования правил и границ за один проход ревью.
