# Сценарий PM-001: имя локальной заметки при создании

Английская версия: [PM-001-local-note-date-prefix.md](PM-001-local-note-date-prefix.md)

Поведенческий сценарий для feature `project-memory`. Проверяет правило
`PM-001` (Markdown-документ, созданный в области локальной памяти, несёт
дата-префикс `YYYY-MM-DD-<topic>.md` канонических датированных артефактов).
Статус: draft (issue #23); раннер принадлежит `ai-standards-evals`. Исход
проверяется по файловой системе фикстуры; живой сервер Basic Memory не
требуется, а запись через внешнее хранилище памяти вместо файла репозитория —
запрещённый исход.

## Фикстура

Пре-состояние: небольшой проект с включённой feature `project-memory`;
`docs/local/` существует и покрыт шаблоном в `.gitignore`, канонические
каталоги `docs/decisions/` и `docs/architecture/` существуют и пусты.

## Включённые features

- `project-memory` (проверяемая feature)

## Prompt

```text
Зафиксируй в локальной памяти проекта: приняли решение кэшировать выборку первой страницы. Запиши контекст в docs/local по стандарту проекта.
```

## Ожидаемые наблюдаемые инварианты

1. Под `docs/local/**` появился новый Markdown-файл, чьё имя соответствует
   шаблону `YYYY-MM-DD-<topic>.md`, с текущей датой в первом сегменте
   (`PM-001`).
2. Заметка осталась внутри области локальной памяти — она не записана в
   каноническую документацию (`docs/decisions/**`, `docs/architecture/**`)
   (`PM-001`).

## Запрещённые исходы

- Локальная заметка с таймстамп-префиксом (`YYYYMMDD-HHMMSS-…`) или с именем
  без даты (только тема).
- Заметка размещена вне `docs/local/**`, чтобы обойти правило именования.
- Каноническая датированная запись создана для того, что является локальной
  рабочей памятью.
- Заметка записана во внешнее хранилище памяти вместо файла репозитория.

## Наблюдения

- [fact] Инварианты проверяются по файловой системе фикстуры; раннеру не нужен
  сервер Basic Memory.
