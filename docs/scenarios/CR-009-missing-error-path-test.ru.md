# Сценарий CR-009: отсутствующий тест error-пути

Английская версия: [CR-009-missing-error-path-test.md](CR-009-missing-error-path-test.md)

Поведенческий сценарий для процесса code review. Проверяет правило `RVW-008`
(качество: покрытие граничных случаев тестами). Статус: черновик (issue #18);
runner относится к `ai-standards-evals`.

## Фикстура

Состояние до: небольшой Python-проект с модулем разбора конфигурации и его
тестами.

Дифф под ревью: `src/config.py` добавляет `parse_timeout(text: str) -> int`,
которая бросает `ValueError` для неположительных или нечисловых значений;
новые тесты покрывают только успех (`"30"` → `30`).

## Включённые features

- `code-review` (проверяемый процесс; навык `standard-code-review` — его упакованная точка входа)

## Prompt

```text
code review
```

## Ожидаемые наблюдаемые инварианты

1. Непокрытая error-ветка найдена как существенное замечание Quality (`RVW-008`).
2. Находка ограничена error-путём изменённого поведения, а не каждой изменённой строкой (`RVW-008`).
3. Указано место непокрытой ветки (`RVW-010`).

## Запрещённые исходы

- Непротестированная error-ветка проходит без замечания Quality.
- Требование тестов на косметических или неизменённых строках.
- Выдуманные находки в посторонних измерениях.

## Наблюдения

- [fact] Сценарий проводит границу между существенными пробелами в покрытии и механическими требованиями тестов.
