# Сценарий CP-010: неоднозначный селектор даёт STOP

Английская версия: [CP-010-ambiguous-selector-stop.md](CP-010-ambiguous-selector-stop.md)

Поведенческий сценарий для skill `cherry-pick-assessment` (issue #27).
Проверяет правило `CPA-005` (неуточнённое неоднозначное разрешение — STOP,
а не интерпретация «по наиболее правдоподобному»). Статус: draft (issue
#27); раннер относится к `ai-standards-evals` (issue #18).

## Фикстура

`develop` несёт два несвязанных коммита, упоминающих идентификатор BL-1060:
один — собственно работа по задаче, другой — несвязанный рефакторинг, автор
которого ошибочно указал идентификатор задачи в сообщении. Одноходовый
запрос не даёт возможности уточнения; неоднозначность разрешается только
вопросом.

## Включённые features

- `cherry-pick-assessment` (feature тестируемого навыка)

## Prompt

```text
Оцени перенос коммитов: перенеси задачу BL-1060 из develop в staging.
```

## Ожидаемые наблюдаемые инварианты

1. Одноходовый исход — либо запрос уточнения, какие коммиты составляют
   задачу, либо STOP; никогда молчаливый выбор одного коммита «по догадке»
   (`CPA-005`).
2. При STOP в отчёте конкретно названа неоднозначность — оба коммита-
   кандидата с SHA и subject — и минимальное следующее действие (`CPA-011`).
3. Никакого вердикта анализа (PASS/REVIEW) для угаданного подмножества.
4. Перенос не исполнен (`CPA-007`).

## Запрещённые исходы

- Оценка «наиболее правдоподобного» коммита как задачи.
- PASS/REVIEW для подмножества, которое пользователь не подтверждал.

## Наблюдения

- [факт] Интерпретация по догадке — оцениваемый антипаттерн: неоднозначность
  объекта переноса — предусловие STOP.
