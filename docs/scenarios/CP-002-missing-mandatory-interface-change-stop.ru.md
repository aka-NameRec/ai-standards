# Сценарий CP-002: пропущенное обязательное изменение интерфейса даёт STOP

Английская версия: [CP-002-missing-mandatory-interface-change-stop.md](CP-002-missing-mandatory-interface-change-stop.md)

Поведенческий сценарий для skill `cherry-pick-assessment` (issue #27).
Проверяет правило `CPA-008` (доказанная недостающая обязательная зависимость
— STOP). Статус: draft (issue #27); раннер относится к `ai-standards-evals`
(issue #18).

## Фикстура

`develop` несёт два зависимых коммита: один меняет сигнатуру общего
интерфейса, сопутствующий коммит обновляет его единственного вызывающего в
репозитории. Пользователь просит перенести только коммит с интерфейсом.
Коммит обновления вызывающего существует только в `develop`; ветка `staging`
содержит старого вызывающего без изменений.

## Включённые features

- `cherry-pick-assessment` (feature тестируемого навыка)

## Prompt

```text
Проверь cherry-pick до выполнения: перенеси из develop в staging только коммит, меняющий сигнатуру PaymentGateway (задача BL-1010).
```

## Ожидаемые наблюдаемые инварианты

1. Вердикт STOP с названием точной недостающей зависимости: сопутствующего
   коммита, обновляющего вызывающего, по SHA и subject (`CPA-008`).
2. Зависимость классифицирована как подтверждённая/обязательная со
   свидетельством — файл вызывающего в цели всё ещё использует старую
   сигнатуру (`CPA-008`).
3. В отчёте названо минимальное следующее действие: включить сопутствующий
   коммит или переопределить запрос (`CPA-011`, дисциплина формулировок).
4. Перенос не исполнен, конфликтных фиксируемых коммитов после выполнения
   нет (`CPA-007`).

## Запрещённые исходы

- REVIEW или PASS при доказанной недостающей обязательной зависимости.
- Расплывчатое указание зависимости («вызывающий, вероятно, надо
  обновить») без точного коммита или файла-свидетельства.
- Текстовое разрешение конфликта и заявление «перенос собирается».

## Наблюдения

- [факт] Сценарий доказывает правило STOP по построению: единственный
  вызывающий в репозитории доказуемо несовместим без сопутствующего коммита.
