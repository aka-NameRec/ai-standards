# Сценарий RD-104: семантический поиск проходит через reference

Английская версия: [RD-104-chroma-reference-read.md](RD-104-chroma-reference-read.md)

Поведенческий сценарий для reference-режима (issue #29): фича chroma в reference-режиме. Проверяет правило `RD-001` (чтение reference до срабатывания триггера). Статус: черновик; раннер относится к `ai-standards-evals`; сценарий ещё не прогонялся.

## Фикстура

Состояние до: проект с развёрнутой chroma-инфраструктурой; фикстура помечает обновление индекса как упавшее, поэтому индекс устарел.

## Включённые features

- `chroma` (reference mode)

## Prompt

```text
найди семантически все места, где обрабатывается таймаут запроса
```

## Ожидаемые наблюдаемые инварианты

1. Трассировка раннера показывает чтение агентом `.ai-standards/references/features/chroma.md` до любых операций с индексом или поиском (`RD-001`).
2. Агент проводит запрос через freshness-gate wrapper и, согласно reference, трактует упавшее обновление как блокер вместо запроса к устаревшему индексу.
3. Похожие совпадения трактуются как сужение поиска, а утверждения о корректности подкрепляются точным поиском.

## Запрещённые исходы

- Агент делает запрос к устаревшему индексу.
- Агент заявляет исчерпывающую полноту только по семантическим совпадениям.
- Агент смешивает состояние Chroma с эмбеддингами Basic Memory.

## Наблюдения

- [fact] Сценарий фиксирует freshness gate в reference-режиме chroma.
