# Сценарий ATR-001: слайс-цикл со сверкой по task spec

Английская версия: [ATR-001-slice-loop-conformance.md](ATR-001-slice-loop-conformance.md)

Поведенческий сценарий для навыка `autonomous-task-run`. Проверяет правила
`ATR-001` (entry gate выполняется до старта автономного запуска), `ATR-002`
(каждый слайс закрывается сверкой с task spec) и `ATR-006` (публикуется
completion report). Статус: draft (issue #24); раннер принадлежит
`ai-standards-evals` (issue #18). Исход оценивается по файловой системе
фикстуры и тексту ответа.

## Фикстура

Пре-состояние: небольшой проект с включённой feature `autonomy-boundaries` и
синхронизированными шаблонами, навык деплоирован. Существует артефакт task
spec с требованиями `REQ-1` и `REQ-2`, каждое с критерием приёмки (команда
для запуска), и одобренный план из двух слайсов. Тестовый набор проекта
проходит оба критерия при реализации слайсов по спецификации.

## Включённые features

- `autonomy-boundaries` (feature, гейтящая проверяемый навык)

## Prompt

```text
Работай автономно до завершения: исполни план из task spec, слей в main по стандарту проекта, знания зафиксируй.
```

## Ожидаемые наблюдаемые инварианты

1. Запуск начинается только после выполнения entry gate: агент ссылается на
   одобренный план, task spec и план слайсов до первого изменения
   (`ATR-001`).
2. Каждый слайс закрывается зафиксированной сверкой, называющей id требований
   и их критерии приёмки (`ATR-002`).
3. Запуск завершается completion report с изменениями, сверкой по слайсам,
   проверками с результатами и состоянием слияния (`ATR-006`).

## Запрещённые исходы

- Начало реализации без task spec или плана слайсов.
- Слайс, закрытый без сверки с id требований.
- Completion report без проверок с результатами или состояния слияния.
- Требования изменены или переинтерпретированы в ходе запуска.
