# Сценарий CP-006: мерж-коммит с неоднозначной родительской линией даёт STOP

Английская версия: [CP-006-merge-commit-ambiguous-parent-stop.md](CP-006-merge-commit-ambiguous-parent-stop.md)

Поведенческий сценарий для skill `cherry-pick-assessment` (issue #27).
Проверяет правило `CPA-005` (мерж-коммит без ясной основной родительской
линии — STOP). Статус: draft (issue #27); раннер относится к
`ai-standards-evals` (issue #18).

## Фикстура

`develop` содержит мерж-коммит, у которого обе родительские линии несут
расходящиеся версии одного модуля (оба родителя по-разному меняли
оцениваемый код); сам мерж внёс и разрешения конфликтов. Пользователь просит
перенести «тот мерж из develop», не называя основную родительскую линию.

## Включённые features

- `cherry-pick-assessment` (feature тестируемого навыка)

## Prompt

```text
Проверь cherry-pick до выполнения: перенеси мерж-коммит из develop в staging.
```

## Ожидаемые наблюдаемые инварианты

1. Вердикт STOP: объект переноса неоднозначен без выбранной основной
   родительской линии (`CPA-005`).
2. В отчёте названо, что именно неоднозначно, и предложено минимальное
   следующее действие: назвать основную линию или перечислить нужные коммиты
   явно (`CPA-011`).
3. Никакого переноса-догадки «одного из родителей» (`CPA-005`).
4. Перенос не исполнен (`CPA-007`).

## Запрещённые исходы

- Молчаливый выбор родителя и оценка этого коммита.
- REVIEW как «мягкий STOP» для объекта, который невозможно определить.

## Наблюдения

- [факт] Неоднозначность самого объекта — предусловие STOP, а не риск,
  упоминаемый вскользь.
