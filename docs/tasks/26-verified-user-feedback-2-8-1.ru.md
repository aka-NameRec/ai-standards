# Задача 26: верифицированный отзыв пользователя о 2.8.1

Локализованная версия: [26-verified-user-feedback-2-8-1.md](26-verified-user-feedback-2-8-1.md)

## Статус

Завершено: отзыв архивирован, все шесть выявлений верифицированы по `main`
на `50ab280`, результаты оформлены задачей на русском — issue #26
(https://github.com/aka-NameRec/ai-standards/issues/26).

## Объём работ

- Входящий отзыв пользователя заархивирован дословно как
  [../archive/2026-10-12-ai-standards-2.8.1-defects.md](../archive/2026-10-12-ai-standards-2.8.1-defects.md).
  Контекст: проект devcats, обновление с 2.5.0 до 2.8.1, агенты `claude` и
  `cursor`; фичи `code-review`, `autonomy-boundaries`, `knowledge-capture`,
  `basic-memory` включены, `project-memory` выключена.
- Все шесть выявлений проверены; ни одно не отклонено:
  1. `standard-code-review.procedure.md` разворачивается только для `kilo`
     (`AGENT_TEMPLATES` в `scripts/ai_sync.py`); копия для `codex` ссылается
     на отсутствующий `references/procedure.md`, копии `claude`/`cursor` —
     на сокращённый `AGENTS.md`: список «Safe to fix without asking», порядок
     «ревью → правки → отчёт», правило реальных объёмов данных и строка
     прохода Correctness существуют только в процедуре с `34baa19` (M1, 2.6.0).
  2. Шаг 6 `autonomous-task-run` (согласие на поток коммитов) противоречит
     пункту «Never» навыка `capture-knowledge` на шаге 7; оговорка о
     старшинстве живёт только в решении о принятии навыка и его тексте.
  3. Шаг 7 требует фиксации знаний вне зависимости от фич `knowledge-capture`
     и `project-memory`; место `docs/tasks/` захардкожено, ключа манифеста нет.
  4. Шаг 1 сам задаёт форму ветки вместо обращения к правилам проекта, как
     шаги 6 и 9 делают для коммитов и слияния.
  5. `fragments/tools/basic-memory.md` по-прежнему снимает с `docs/local/**`
     все правила канонических заметок вопреки сужению 2.8.0 (issue #23), а
     перекрёстная ссылка «see Project Memory» висячая при выключенной
     `project-memory`.
  6. Шаг 5 режима Upgrade навыка `update-ai-standards` молча разворачивает
     шаблоны (включая новые навыки, привязанные к включённым фичам) до
     анонса шага 6 и подтверждения шага 7; ключа отказа от отдельного шаблона
     в манифесте нет.

## Проверки

- Вводные отзыва: `meta.toml` — релиз `2.8.1`/`2026-10-11`; метка
  `2.8.1-2026-10-11` существует; коммиты после метки (`45daf97`, `ca08731`,
  `50ab280`) затрагивают только `CHANGELOG.md` и документы решений/задач.
- Каждое выявление проверено по исходникам репозитория (шаблоны, фрагменты,
  `scripts/ai_sync.py`, `registry.toml`, `CHANGELOG.md`, решения), а не по
  тексту отзыва; `aa7ac33` (2026-09-01) подтверждён как последнее касание
  шаблонов код-ревью для `claude`/`cursor`.
- Поведенческие прогоны для затронутых навыков не выполнялись; сценарии
  `ai-standards-evals` этой задачей не прогонялись.
