# 0tkiyqo — режим установки в скилле обновления и релиз 2.2.1

English source of truth: [0tkiyqo-update-skill-install-mode-221.md](0tkiyqo-update-skill-install-mode-221.md)

Дата: 2026-08-30 · Выпущено как 2.2.1 (тег `2.2.1-2026-08-30`, GitHub-релиз опубликован как Latest; `main` @ `cb65813` == origin)

## Триггер

После 2.2.0 сопровождающий расширил цель: ai-standards развёрнут в проектах, которые ему не принадлежат, и оба сценария — установка в проект без развёртывания и обновление старого — должны работать от коротких промптов. Верификация формулировок подняла решающие вопросы: голый URL доставляет код, но не процедуру, поэтому канонические промпты должны называть файл процедуры; а дайджест, анонсирующий по одному `since`, даёт ложноположительные для развёртываний с актуальным контентом и устаревшим пином (наблюдалось вживую на cockpit: пин 2.1.0, контент 2.2.0, две фичи уже включены).

## Что сделано

- **Скилл `update-ai-standards` стал двухрежимным и холодно-стартовым** (ветка `feat/0tkiyqo-skill-install-mode`, коммит `6cd0f23`): **Install mode** (добыть исходник, обследовать проект — существующий `AGENTS.md` и его происхождение, стеки, раскладку и язык документации, наличие ConPort/Basic Memory, CI, трекер, агентские окружения — предложить фичи по одной строке с рекомендациями, развернуть подтверждённый набор через `init-project` + манифест + `render` + `sync-templates` + `check` + `doctor`); **хедер холодного старта**, делающий файл выполняемым прямо из чекаута; **Upgrade mode** с бутстрап-преамбулой (`render` + `sync-templates` до дайджеста) и **осведомлённым дайджестом**, анонсирующим только фичи, которые новые *и* отсутствуют в списке `features` манифеста. Адаптеры claude/cursor регенерированы из тела SKILL.md — три шаблона не могут разъехаться.
- **`standards_source` стандартизирован**: записывается при установке в `[metadata]`, попадает в шапку `AGENTS.md` существующим каналом метаданных, читается каждым следующим обновлением — промпты обновления после этого в URL не нуждаются.
- **Канонические промпты опубликованы** в README («Standard Install And Update Prompts», en + ru) и дословно в release notes 2.2.1: холодная установка (URL + файл процедуры), голофразное обновление для развёртываний этого или более нового релиза и бутстрап-промпт обновления для старых развёртываний.
- **Decision record** `2026-08-29-standards-install-and-cold-start` (en + ru): один двухрежимный скилл вместо отдельного скилла установки; URL-одиночка отклонена как каноническая форма; осведомлённость дайджеста о включённом.
- **Релиз 2.2.1** (коммит `cb65813` после fast-forward слияния — `bump-version tag` принуждает тегирование из `main`; урок стоил одной неудачной попытки тега): `bump-version save --part patch` (2.2.1, 2026-08-30), CHANGELOG `[2.2.1]` с разделом Canonical Prompts, подъём констант в тестовой фикстуре, пуш тега, GitHub-релиз опубликован с промптами дословно.

## Верификация

104 теста проходят; `mypy` strict и `ruff` чисты; `ai-sync check` зелёный; `doctor` — ноль ошибок; `gh release view` подтвердил релиз как Latest с целью `main`, не черновик. Состояние пуша cockpit проверено до попытки — сопровождающий уже запушил `917e091` (получено «Everything up-to-date»).

## Намеренно не сделано

- `standards_source` остаётся конвенцией, а не принуждением: развёртывания, установленные до 2.2.1, не имеют его, пока обновление не запишет.
- Никаких изменений кода `scripts/ai_sync.py` — вся фича это текст процедуры, документация и тесты; модульный контракт на этот раз правок не требовал.
- Бутстрап cockpit не завершался отсюда: его пин 2.1.0 против выпущенной 2.2.1, и завершение относится к живому прогону голой фразы в сессии cockpit.

## Контекст для следующей сессии

- Первый прогон «обнови ai-standards» в cockpit совмещается с первым живым багофиксом-тестом скилла 2.2.1: он обнаружит дрейф пина, анонсирует `code-review` и `knowledge-capture` (осведомлённо о включённом), включит по подтверждению и переведёт пин.
- `bump-version` без аргументов предлагает minor; патч-релизы требуют явного `--part patch`.
- Релизные операции требуют чистого дерева, а тегирование — ветки `main`; слейте фичевые ветки до тегирования.

## Observations

- [decision] Скилл обновления двухрежимный (Install/Upgrade) и самодостаточен из чекаута; канонические промпты называют файл процедуры, а не только URL репозитория.
- [fact] Дайджест обновления анонсирует только фичи, которые новые и отсутствуют в списке `features` манифеста; уже включённое не анонсируется повторно.
- [fact] `bump-version save` требует чистого дерева, а `bump-version tag` — ветки `main`; предложение версии по умолчанию — minor, патч-релизы требуют `--part patch`.
- [fact] `standards_source` записывается при установке и попадает в шапку `AGENTS.md` через канал метаданных манифеста.
