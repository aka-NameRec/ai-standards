# Задача 18: контракты сценариев для ai-standards-evals

Русская документация — основной язык проекта. Английские термины
(`standard-code-review`, `rule_map.toml`, `scenario-format.md`) сохраняются
дословно.

## Что сделано

В рамках спецификации репозитория `ai-standards-evals` (issue #18) добавлены
шесть поведенческих контрактов сценариев `docs/scenarios/CR-004`–`CR-009`
(пары EN + RU по контракту `scenario-format.md`):

- **CR-004** — реальный дефект корректности (инвертированное граничное условие,
  которое собственные тесты фикстуры не ловят); правила `RVW-004`, `RVW-010`,
  `RVW-011`, `RVW-014`.
- **CR-005** — новое внутреннее дублирование без готового помощника
  (различение DRY и Reuse); правило `RVW-006`.
- **CR-006** — нарушение принятого архитектурного решения (ADR-004); правила
  `RVW-005`, `RVW-011`.
- **CR-007** — кажущееся нарушение, опровергаемое полным кодом (валидация в
  декораторе вне диффа); правила `RVW-012`, `RVW-014`.
- **CR-008** — верификация недоступна в окружении (драйвер БД отсутствует);
  правило `RVW-019`.
- **CR-009** — отсутствующий тест error-пути; правило `RVW-008`.

В `rule_map.toml` сценарные привязки добавлены правилам `RVW-004`, `RVW-005`,
`RVW-006` (+`CR-005`), `RVW-008`, `RVW-011`, `RVW-012`, `RVW-014` (+`CR-007`),
`RVW-019` (+`CR-008`).

## Нумерация

Сверка спецификации #18 с фактическим состоянием
(комментарий https://github.com/aka-NameRec/ai-standards/issues/18#issuecomment-5755833038):
ID сценариев стабильны, номера CR-001–CR-003 и TRG-001 заняты существующими
контрактами, поэтому сценарии предложения получили номера CR-004–CR-009
(соответствие приведено в комментарии к issue).

## Валидация

- `uv run pytest tests/test_rule_map.py` — 9 passed; полный набор — 141 passed.
- `uv run ai-sync render --project-root .` идемпотентен (ID правил не
  рендерятся в `AGENTS.md`).
- Реализации раннеров и прогоны выполняются в репозитории
  `ai-standards-evals` (baseline CR-004, CR-006–CR-009 PASS; CR-005 FAIL —
  нарушение порядка секций отчёта, зафиксировано как поведенческий сигнал).

## Вне области

- Реализация раннеров, фиксатур и scorers — репозиторий `ai-standards-evals`.
- Cross-agent матрица и повторные trials — там же.
