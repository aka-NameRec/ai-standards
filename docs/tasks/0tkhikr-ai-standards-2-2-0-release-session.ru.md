# 0tkhikr — релизная сессия ai-standards 2.2.0

English source of truth: [0tkhikr-ai-standards-2-2-0-release-session.md](0tkhikr-ai-standards-2-2-0-release-session.md)

Дата: 2026-08-28 · Ветка: коммиты прямо в `main` по решению пользователя (`f6206b1`, `aab626e`, `fc2e9a9`, `8891313`, `9b1b0a8`, `c29fb57`, `9ae2d23`, `73c6c10`; релизный коммит и тег `2.2.0-2026-08-28` следуют за этой записью)

## Триггер

Черновик контрибьютора по обнаружению модульных контрактов (`docs/archive/0tkgv0g-module-contract-discovery-gate.md`, переписка от 2026-07-28) ждал продвижения; сопровождающий дополнительно запросил строку версии набора правил в отчётах code review, определённый workflow обновления стандартов (запрос «обнови ai-standards» был недоопределён в четырёх местах), продвижение кокпит-правила стиля ответов и релиз 2.2.0.

## Что сделано

- **Строка версии в отчёте code review** (`f6206b1`): каждый отчёт открывается строкой `ai-standards <версия>` из шапки собранных инструкций, чтобы вставленный куда-либо отчёт фиксировал, с каким набором правил выполнялось ревью.
- **Workflow обновления стандартов** (`fc2e9a9`, `8891313`): скилл `update-ai-standards` развёртывается с каждым развёртыванием, объявившим агентов, — без фиче-гейта; включённые фичи перерендериваются молча, фичи, добавленные после зафиксированной версии, анонсируются по `[feature_meta].since` с рекомендациями относительно стеков проекта, и включается только подтверждённое. В `registry.toml` добавлен `[feature_meta]`; дрейф пина репортится (`check` падает, `render`/`update` предупреждают, `doctor` сообщает `standards-version-drift`); бутстрап вынесен в release notes.
- **Гейт обнаружения модульных контрактов** (`aab626e`, `9b1b0a8`, `c29fb57`, `9ae2d23`): решение о размещении (отдельная opt-in фича, а не расширение `structured-artifacts`), затем фича `module-contract-gate` — композит в реестре, несущий и политику контрактов; строгое правило почти дословно, пропорциональный discovery в начале задачи, условные шаги Basic Memory, эскалация через `Autonomy Boundaries`. Включён для ai-standards и cockpit.
- **Фича `response-language-style`** (`73c6c10`): естественный русский в ответах, без англицизмов с ходовыми русскими эквивалентами, без сленга, дисциплина аббревиатур, дословные технические имена. Opt-in; продвинута из кокпит-правила, блок которого стал короткой строкой-носителем в override cockpit.
- **Релиз 2.2.0**: чистка (удалены 6 слитых веток и `pr-3`, устаревшие worktree подрезаны), `bump-version save --part minor` (2.2.0, 2026-08-28), заголовок CHANGELOG `Unreleased` → `[2.2.0] — 2026-08-28` с разделом Upgrade Notes (бутстрап), подъём версии в тестовой фикстуре.

## Верификация

103 теста проходят; `mypy` strict и `ruff` чисты; `ai-sync check` зелёный для ai-standards и cockpit; `doctor` — ноль ошибок в обоих; рендеры идемпотентны. Релизный коммит и тег следуют за этой записью.

## Намеренно не сделано

- Гейт и стиль ответов остаются opt-in — без включения по умолчанию для потребителей (решение о размещении той же даты).
- Без usage-гида для `response-language-style`: фрагмент самодостаточен, как и core-фрагменты.
- Заметки индекса Basic Memory для модульных контрактов не писались; фрагмент определяет, что такие записи должны нести, наполнение индексов — задача каждого проекта.
- Устаревшая удалённая ветка `origin/feature/0tkf6ym-capture-knowledge` оставлена до явного одобрения удаления сопровождающим.

## Контекст для следующей сессии

- Одобрение пуша остаётся за сопровождающим по каждой партии; коммиты этой сессии едут партиями, которые сопровождающий пушит сам.
- Скилл обновления анонсирует `code-review`, `knowledge-capture`, `module-contract-gate` и `response-language-style` развёртываниям с пином ниже 2.2.0, как только тег будет запушен.
- Бэклог гигиены (заметки без наблюдений/связей, двуязычные дубли H1) намеренно не менялся.

## Observations

- [decision] Гейт обнаружения модульных контрактов выходит как opt-in фича `module-contract-gate`; скилл обновления анонсирует его старым развёртываниям по `[feature_meta].since`.
- [decision] Скилл обновления развёртывается без фиче-гейта, потому что обслуживает сам ai-standards, а не процесс проекта.
- [fact] Голый запрос «обнови ai-standards» теперь имеет определённую процедуру: молчивое обновление включённых фич, дайджест нового с момента пина, одно подтверждение, перевод пина, верификация.
- [fact] `ai-sync check` падает, пока `ai_standards_version` расходится с используемым исходником; `render`/`update` предупреждают, `doctor` сообщает дрейф.
