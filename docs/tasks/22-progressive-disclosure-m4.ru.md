# 22 — Прогрессивное раскрытие M4: reporting reference, CR-010–CR-012, eval-гейт

English version: [22-progressive-disclosure-m4.md](22-progressive-disclosure-m4.md)

Дата: 2026-09-23 · Ветки: `rules-change/22-m4-reporting-reference`
(ai-standards) + `STD-CHANGE-0001-cr010-cr012` (ai-standards-evals)

## Триггер

Issue #22: продолжить работу по размещению знаний context-architecture после
фазы 8 (M1–M3) — вынести деталь политики оформления отчёта code review из
всегда загруженного фрагмента, сначала поведенческая верификация. Change set
`STD-CHANGE-0001` по cross-repo flow.

## Что сделано

- Контракты сценариев `CR-010`–`CR-012` (EN/RU) привязаны к `RVW-015`–`RVW-018`,
  `RVW-022`, `RVW-024`, `RVW-030` в `rule_map.toml`; CR-010 закрывает безсценарность
  правил метаданных отчёта, которые отвергнутая попытка M3 показала как нагруженные,
  CR-011 закрепляет маршрутизацию через reporting reference, CR-012 — fallback при
  отсутствии шаблонов, который не наблюдал ни один прежний сценарий.
- Новый шаблон `templates/code-review-reporting.reference.md`, деплой через
  `INFRA_TEMPLATES` в `.ai-standards/references/code-review-reporting.md`
  (feature `code-review`); фрагмент хранит триггер, охват, инварианты находки,
  указатель на форму, fallback-порядок, дословный инвариант строки версии и правило
  языка сессии; полная русская легенда локализации переехала в рабочий пример;
  минимальная легенда секций возвращена в fallback-буллет после того, как eval-гейт
  поймал регрессию (ниже).
- `ai-standards-evals`: билдеры фикстур (CR-010/011 синхронизируют шаблоны,
  CR-012 — никогда), сценарные скореры, снапшот датасета, покрытие — правила
  со сценариями 21/52 (было 15/52); фиксы раннера (матричная раскладка в
  `collect_runs`/`discover_runs`, исключение находок об отсутствующем покрытии
  на тестовых путях из нарушений охвата, маркер pre-existing по исходу, а не
  дословно, нечёткий fallback-матчер для CR-012).

## Верификация

- `ai-standards`: 148 тестов зелёные; `ai-sync render` идемпотентен;
  `ai-sync doctor` без ошибок. `ai-standards-evals`: ruff, mypy, pytest зелёные.
- Eval-гейт: первая кандидатская эпоха провалена — отчёты fallback-пути
  деградировали в смешанную форму без всегда загруженной легенды (урок M3 в новом
  месте). Исправлено возвратом минимальной легенды (~230 байт); отклонённая эпоха
  заархивирована.
- Финальное сравнение (baseline `2.6.0-2026-09-23` vs кандидат, по 2 эпохи,
  LLM-судья GLM-5.3): машинный вердикт ACCEPT, downgrade'ов нет (CR-009: baseline
  MIXED → кандидат PASS; CR-010: у кандидата MIXED из-за вариации формы публикации);
  судья 15/15 pass. Отчёт:
  `ai-standards-evals/reports/20260923-std-change-0001-comparison.md`.
- Замеры: секция `Code Review` 7 781 → 5 835 байт; собственный `AGENTS.md`
  61 888 → 60 034 байта.

## Заметки

- Push и слияние в `main` сознательно не выполнялись: push требует явного одобрения
  пользователя, а merge-гейт требует приложения этого сравнения к слиянию — оба
  шага ждут решения пользователя.
- M5 (Basic Memory Usage) и M6 (Project Memory, перечисления артефактных политик)
  остаются следующими гейтованными ходами; для M5 нужен минимум один собственный
  поведенческий сценарий, чтобы гейт был осмысленным.
