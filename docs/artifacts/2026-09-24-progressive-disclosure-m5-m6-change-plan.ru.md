# План изменений: этап 3 прогрессивного раскрытия — M5 basic-memory operations и M6 компрессия (issue #22)

English original: [2026-09-24-progressive-disclosure-m5-m6-change-plan.md](2026-09-24-progressive-disclosure-m5-m6-change-plan.md)

Change set: `STD-CHANGE-0001` (продолжение) · Ветки:
`rules-change/22-m4-reporting-reference` (ai-standards),
`STD-CHANGE-0001-cr010-cr012` (ai-standards-evals) · Дата: 2026-09-24

## Цель

Завершить issue #22: перенести операционную деталь basic-memory в деплоимую
reference (M5), сжать перечисления project-memory и артефактных политик (M6),
дать правилам basic-memory первую поведенческую покрытия. Слияние в `main` —
после прохождения гейтов.

## Объём

- M5: новый `templates/basic-memory-operations.reference.md`, деплой через
  `INFRA_TEMPLATES` в `.ai-standards/references/basic-memory-operations.md`
  (feature `basic-memory`). Фрагмент хранит routing (слои, выделенное дерево,
  каноническое vs рабочая память, жанровая доктрина, скоупинг MCP), триггеры
  синхронизации, сжатое правило формы заметок и указатель; в reference
  переезжают паттерны маскирования, детали пермалинков и legacy-флагов,
  механика переименований, специфика инструментов починки и reindex-матрица.
- Новый префикс правил `BM-*` в `rule_map.toml` (у фрагмента basic-memory не
  было id); контракты сценариев `BM-001` (форма заметки при создании,
  проверяется по файловой системе фикстуры) и `BM-002` (триггер гигиены
  синхронизации после VCS-операций, проверяется по тексту ответа), пары EN/RU.
- M6: компрессия прозы `fragments/tools/project-memory.md` и
  `fragments/process/structured-artifacts.md` — тот же контент, меньше
  токенов; без перемещений и без изменения нормативики.
- `ai-standards-evals`: билдеры фикстур и скореры для BM-001/BM-002 (живой
  сервер Basic Memory не требуется; использование BM MCP вместо файла
  репозитория — запрещённый исход для BM-001).

Вне объёма: жанровая доктрина остаётся всегда загруженной (по классификации
миграционного плана); релиз/тег в этот change set не входят.

## Риски и инварианты

- Жанровые буллеты — плотный нормативный текст; их компрессия сознательно вне
  объёма M6, чтобы не менять семантику без гейта.
- BM-сценарии не должны касаться реального хранилища Basic Memory пользователя:
  фикстуры рендерят feature `basic-memory` только для контента AGENTS.md,
  а промпты закрепляют файловые исходы внутри фикстуры.
- Гейт M5 честен по глубине: BM-001/BM-002 защищают самые нагруженные
  пользовательские правила (форма заметки, триггеры синхронизации), которые
  остаются всегда загруженными в сжатом виде; перемещённая механика покрывается
  regression-набором и рендер-гарантиями — это зафиксировано, чтобы merge-гейт
  читался правдиво.

## Сессионный конверт

- Не цели: без релиза, без push (требует явного одобрения пользователя), без
  изменений фрагмента code review в этом этапе.
- Стоп-условия: регрессия в eval-гейте без исправимого хода в рамках объёма;
  противоречия контракту формата сценариев.
- Ожидаемые артефакты: этот план (EN/RU), пары сценариев, изменения раннера,
  отчёты сравнения, обновлённые task record и CHANGELOG.

## Верификация

1. `ai-standards`: pytest, идемпотентность рендера, doctor — как прежде.
2. `ai-standards-evals`: ruff, mypy, pytest; смоук-прогоны BM-сценариев.
3. Финальное merge-гейт сравнение: baseline `2.6.0-2026-09-23` против HEAD
   ветки — CR-001..CR-012 как regression, BM-001/BM-002 как новое покрытие,
   с LLM-судьёй; затем слияние в `main` обоих репозиториев (локальные слияния).
