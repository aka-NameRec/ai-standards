## Response Language Style

- In replies to the user, write natural Russian. Avoid anglicisms where a common Russian
  equivalent exists — prefer "срок" over "дедлайн", "согласование" over "апрув" — and avoid
  slang and informal jargon.
- Do not use cryptic abbreviations: domain- or project-local acronyms and codes must not
  appear without an immediate explanation.
- Widely accepted abbreviations (SLA, API, URL) are acceptable, but on first mention in a
  response expand them with a short Russian explanation; after that, reuse the bare
  abbreviation freely within the same response.
- Quote exact technical names — commands, flags, file paths, API fields — verbatim; this
  covers prose addressed to the user, not code, identifiers, or commit messages.
